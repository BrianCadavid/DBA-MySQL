# DBA-MySQL



Repositorio de aprendizaje y prácticas de administración de bases de datos con MySQL.



## Objetivo



- Desarrollar conocimientos en administración de bases de datos MySQL.

- Practicar consultas SQL en escenarios reales.

- Documentar ejercicios y aprendizajes.

- Construir un portafolio técnico orientado a DBA Junior.



## Tecnologías utilizadas



- MySQL

- SQL

- Git

- GitHub
